# Hello, World!

Welcome to your new blog! This is an example blog post written in MDX format.

## What is MDX?

MDX is a format that lets you write JSX in your Markdown documents. You can import components, embed interactive demos, and more.

## Getting Started

To create a new blog post:

1. Create a new `.mdx` file in the `content` directory
2. Add frontmatter at the top with:
   - `title`: The title of your post
   - `publishedAt`: The publication date (YYYY-MM-DD format)
   - `summary`: A short description of your post
   - `image`: (optional) Path to a featured image

3. Write your content using Markdown syntax
